## 🌟 About the Project

This is a personal portfolio website created to introduce **Parvathy A** and present an overview of her web development interests, educational background, and skills. The page uses a fixed navigation bar to help visitors move between the Home, About, Education, Skills, and Contact sections.

Developed as part of the **PRODIGY Web Development Internship** task series.

## ✨ Features

- 🏠 **Home section** – Introduction and profile image.
- 🙋‍♀️ **About section** – A short personal introduction.
- 🎓 **Education section** – Academic background.
- 💻 **Skills section** – Overview of web development skills.
- 📩 **Contact section** – Contact form layout for visitor messages.
- 🧭 **Fixed navigation bar** – Quick links to the different sections.
- 🎨 **Styled interface** – Custom colours, spacing, and navigation hover effects.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/parvathyamvk/prodigy-wd-task-04-personal-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd prodigy-wd-task-04-personal-portfolio
   ```

3. Open `index.html` in your web browser.

No package installation or build tools are required.

## 🔎 Project Notes

- The navigation links jump to the corresponding sections on the page.
- The navigation bar remains fixed at the top while scrolling.
- The contact form is currently a front-end form layout. Its form action points to a placeholder URL (`https://example.com/submit`), so message submission is not connected to a working backend yet.
- The navigation item labelled **Download Resume** currently links to the Contact section; it does not download a resume file in this version.
